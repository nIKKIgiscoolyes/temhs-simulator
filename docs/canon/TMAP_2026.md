# 19. ACCESS CLASSIFICATION SYSTEM

TEMHS uses four primary access categories.

## ACADEMIC

Normal student-access learning areas.

Examples:

- classrooms;
- labs;
- libraries;
- tutoring rooms;
- academic corridors.

## TRANSITIONAL

Access permitted under conditions.

Examples:

- controlled connectors;
- transfer corridors;
- selected elevator lobbies;
- work-adjacent routes.

## RESTRICTED

Ordinary student access prohibited.

Examples:

- controlled archives;
- records rooms;
- construction boundaries;
- staff-only operations;
- secured infrastructure.

## UTILITY

Infrastructure personnel only.

Examples:

- electrical rooms;
- mechanical systems;
- ventilation controls;
- plant equipment;
- service tunnels;
- communications infrastructure.

Every important door and route must have an access classification.
